## ✅ Apa yang Sudah Dibangun

### 1. Inisialisasi Proyek Next.js
- **Framework:** Next.js 16.2.6 (App Router)
- **Bahasa:** TypeScript Strict
- **Styling:** Tailwind CSS v4
- **ORM:** Prisma v7.8.0 (`@prisma/client`)
- **Auth:** NextAuth.js v5 (Credentials Provider + JWT)
- **Validation:** Zod v4
- **Database:** PostgreSQL

### 2. Database Schema (Prisma) — ✅ Selesai
**File:** `backend/prisma/schema.prisma`

10 model utama + 4 tabel pivot:

| Model | Catatan |
|-------|---------|
| `User` | Admin auth (email, password bcrypt, role) |
| `Project` | Portofolio (dengan gallery JSON, SEO fields) |
| `BlogPost` | Artikel (dengan SEO, publishedAt) |
| `Page` | Halaman statis |
| `Team` | Data tim/karyawan |
| `Category` | Kategori general (dibedakan kolom `type`) |
| `Tag` | Tag blog |
| `Testimonial` | Testimoni klien |
| `LeadsLog` | Log klik (read-only) |
| `Setting` | Key-value config |

2 Prisma Enums: `ProjectStatus` (DRAFT/ONGOING/COMPLETED), `TestimonialPlatform` (MANUAL/SOCIAL_MEDIA)

4 tabel pivot (explicit many-to-many):
- `ProjectTeam` (relasi Project ↔ Team + kolom `role`)
- `BlogPostCategory` (relasi BlogPost ↔ Category)
- `BlogPostTag` (relasi BlogPost ↔ Tag)
- `CategoryProject` (relasi Project ↔ Category)
