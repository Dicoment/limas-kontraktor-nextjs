## 🔨 Detail Perubahan

### 1. Fix `prisma/seed.ts` — Kompatibilitas Prisma 7

| Masalah | Root Cause | Perbaikan |
|---------|------------|-----------|
| `Cannot find module '../src/generated'` | Tidak ada `index.ts` di folder `src/generated/` sehingga path tersebut tidak bisa diselesaikan sebagai module | Ganti import path ke `'../src/generated/client'` — entry point yang diekspor oleh generated Prisma Client, berisi `PrismaClient`, semua enums, dan model types |
| `PrismaClientInitializationError` — `new PrismaClient()` tanpa argumen ditolak | Prisma 7 membuat field `adapter` atau `accelerateUrl` menjadi wajib di `PrismaClientOptions` (union type exclusive), tidak boleh kosong | Tambah `adapter: new PrismaPg(process.env.DATABASE_URL!)` sebagai opsi konstruktor |
| Tidak ada pesan error jika `DATABASE_URL` tidak di-set | Adapter akan throwing error turunan yang membingungkan | Tambah guard eksplisit: jika `process.env.DATABASE_URL` kosong, `console.error` dan `process.exit(1)` dengan pesan yang jelas |
| Tidak ada cara menjalankan seeder secara resmi | Tidak ada entry di `scripts` di `package.json` | Tambah `"db:seed": "tsx prisma/seed.ts"` ke `package.json` |

**File yang diubah:**
- `prisma/seed.ts` — baris 1–13
- `package.json` — baris scripts

### 2. Penyempurnaan `Database.md`

Dokumentasi `Database.md` ditulis ulang dengan struktur yang lebih jelas:
- Menambahkan **gambar diagram relasi ASCII** yang menunjukkan 10 model dan 4 tabel pivot beserta kolom-kolom utama
- Memperbarui seluruh blok Prisma 7, penjelasan enum, dan catatan kompatibilitas
- Mendokumentasikan skema `prisma/schema.prisma` yang akurat saat ini
- Menambahkan dokumentasi untuk `prisma/seed.ts` dan cara menjalankannya

### 3. Script `db:seed` di `package.json`

Script `"db:seed": "tsx prisma/seed.ts"` ditambahkan ke blok `scripts` di `package.json`, sehingga seeder dapat dijalankan dengan:
```
npm run db:seed
```
dengan syarat `DATABASE_URL` sudah di-set di environment.
