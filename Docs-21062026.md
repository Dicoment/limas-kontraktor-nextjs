## API Routes

### Pola Umum
- Semua route mengikuti RESTful convention
- Collection routes: `GET` (list), `POST` (create)
- Item routes: `GET` (detail), `PUT` (update), `DELETE` (hapus)

### Daftar API Endpoints

| Method | Endpoint | Deskripsi |
|--------|----------|-----------|
| GET, POST | `/api/blog-posts` | List / buat blog post |
| GET, PUT, DELETE | `/api/blog-posts/[id]` | Detail / update / hapus blog post |
| GET, POST | `/api/categories` | List / buat kategori |
| GET, PUT, DELETE | `/api/categories/[id]` | Detail / update / hapus kategori |
| GET, POST | `/api/leads-logs` | List / buat leads log |
| GET, PUT, DELETE | `/api/leads-logs/[id]` | Detail / update / hapus leads log |
| GET, POST | `/api/pages` | List / buat halaman |
| GET, PUT, DELETE | `/api/pages/[id]` | Detail / update / hapus halaman |
| GET, POST | `/api/projects` | List / buat proyek |
| GET, PUT, DELETE | `/api/projects/[id]` | Detail / update / hapus proyek |
| GET, POST | `/api/settings` | List / buat pengaturan |
| GET, PUT, DELETE | `/api/settings/[id]` | Detail / update / hapus pengaturan |
| GET, POST | `/api/tags` | List / buat tag |
| GET, PUT, DELETE | `/api/tags/[id]` | Detail / update / hapus tag |
| GET, POST | `/api/teams` | List / buat tim |
| GET, PUT, DELETE | `/api/teams/[id]` | Detail / update / hapus tim |
| GET | `/api/testimonials` | List testimoni |
| GET, PUT, DELETE | `/api/testimonials/[id]` | Detail / update / hapus testimoni |
